# 03-流程控制

## 1. 条件判断（if-elif-else）

```python
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 60:
    grade = "C"
else:
    grade = "D"

print(f"等级：{grade}")

# 三元表达式（简写）
result = "及格" if score >= 60 else "不及格"
```

## 2. for 循环

```python
# 遍历列表
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# 配合 range()
for i in range(5):        # 0, 1, 2, 3, 4
    print(i)

for i in range(1, 10, 2): # 1, 3, 5, 7, 9（步长2）
    print(i)

# 遍历字典
person = {"name": "Alice", "age": 25}
for key in person:
    print(key)

for key, value in person.items():
    print(f"{key}: {value}")

# enumerate 获取索引
for index, fruit in enumerate(fruits):
    print(f"{index}: {fruit}")

# zip 并行遍历
names = ["Alice", "Bob"]
ages = [25, 30]
for name, age in zip(names, ages):
    print(f"{name} 今年 {age} 岁")
```

## 3. while 循环

```python
count = 0
while count < 5:
    print(count)
    count += 1
```

## 4. 循环控制

```python
# break：终止整个循环
for num in range(10):
    if num == 5:
        break
    print(num)  # 0,1,2,3,4

# continue：跳过当前迭代
for num in range(5):
    if num == 2:
        continue
    print(num)  # 0,1,3,4

# else：循环正常结束时执行（没被 break）
for i in range(3):
    print(i)
else:
    print("循环正常结束")
```

## 5. 经典练习：九九乘法表

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}×{i}={i*j}", end="\t")
    print()  # 换行
```
