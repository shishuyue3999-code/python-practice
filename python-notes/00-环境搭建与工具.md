# 00-环境搭建与工具

## 1. 安装 Python

1. 访问 [python.org](https://www.python.org/downloads/)
2. 下载最新稳定版（推荐 3.10+）
3. **Windows 安装时勾选** `Add Python to PATH`
4. 验证安装：
   ```bash
   python --version
   ```

## 2. 选择 IDE/编辑器

| 工具 | 特点 | 推荐度 |
|------|------|--------|
| VS Code | 轻量、插件丰富 | ⭐⭐⭐⭐⭐ |
| PyCharm | 功能全面、专业 | ⭐⭐⭐⭐ |
| Jupyter Notebook | 交互式、适合数据分析 | ⭐⭐⭐⭐ |

## 3. 虚拟环境

```bash
# 创建虚拟环境
python -m venv venv

# Windows 激活
venv\Scripts\activate

# macOS/Linux 激活
source venv/bin/activate

# 退出
 deactivate
```

## 4. 第一个 Python 程序

```python
# hello.py
print("Hello, Python!")
```

运行：
```bash
python hello.py
```

## 5. 交互式解释器（REPL）

直接在终端输入 `python` 进入交互模式：
```python
>>> 2 + 3
5
>>> print("交互式执行")
交互式执行
>>> exit()  # 退出
```
