# 01-Python基础语法

## 1. 注释

```python
# 这是单行注释

"""
这是多行注释（文档字符串）
通常用于函数、类的说明
"""
```

## 2. 变量与命名规则

```python
# 变量赋值
name = "Alice"
age = 25
is_student = True

# 命名规则：
# - 只能包含字母、数字、下划线
# - 不能以数字开头
# - 区分大小写
# - 推荐使用 snake_case（下划线命名法）
```

## 3. 基本输入输出

```python
# 输出
print("Hello, World!")
print("姓名:", name, "年龄:", age)

# 格式化输出（f-string，推荐）
print(f"我叫{name}，今年{age}岁")

# 输入（接收的都是字符串）
user_input = input("请输入你的名字：")
print(f"你好，{user_input}!")

# 类型转换
num = int(input("输入一个数字："))
```

## 4. 运算符

```python
# 算术运算符
a = 10 + 3   # 13
b = 10 - 3   # 7
c = 10 * 3   # 30
d = 10 / 3   # 3.333...
e = 10 // 3  # 3 (整除)
f = 10 % 3   # 1 (取余)
g = 10 ** 3  # 1000 (幂运算)

# 比较运算符：== != > < >= <=
# 逻辑运算符：and or not
```

## 5. 代码缩进

Python 用**缩进**表示代码块，而不是大括号：

```python
if age >= 18:
    print("成年人")      # 4个空格缩进
    print("可以考驾照")
else:
    print("未成年人")
print("这行不受 if 影响")  # 无缩进，独立语句
```
