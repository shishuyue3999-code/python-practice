# 07-文件与异常处理

## 1. 文件读写

### 基本操作

```python
# 读文件
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()          # 读取全部
    lines = f.readlines()       # 读取为列表

# 写文件（覆盖）
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    f.write("第二行\n")

# 追加模式
with open("log.txt", "a", encoding="utf-8") as f:
    f.write("新增一行\n")
```

### 文件打开模式

| 模式 | 说明 |
|------|------|
| `r` | 只读（默认） |
| `w` | 只写，覆盖 |
| `a` | 追加 |
| `x` | 创建新文件，已存在则报错 |
| `b` | 二进制模式（如 `rb`, `wb`） |
| `+` | 读写模式 |

## 2. 异常处理

```python
try:
    num = int(input("输入数字："))
    result = 10 / num
    print(result)
except ValueError:
    print("输入的不是数字！")
except ZeroDivisionError:
    print("不能除以零！")
except Exception as e:
    print(f"未知错误：{e}")
else:
    print("没有异常时执行")
finally:
    print("无论有无异常都执行")
```

## 3. 自定义异常

```python
class ValidationError(Exception):
    pass

def validate_age(age):
    if age < 0:
        raise ValidationError("年龄不能为负数")
    return age
```

## 4. 上下文管理器（with 语句原理）

```python
# 自定义上下文管理器
class ManagedFile:
    def __init__(self, filename):
        self.filename = filename
    
    def __enter__(self):
        self.file = open(self.filename, "r")
        return self.file
    
    def __exit__(self, exc_type, exc_val, exc_tb):
        if self.file:
            self.file.close()

with ManagedFile("data.txt") as f:
    print(f.read())
```

## 5. 路径处理（pathlib）

```python
from pathlib import Path

# 创建路径对象
p = Path("./data/subdir/file.txt")

p.name          # "file.txt"
p.parent        # Path("./data/subdir")
p.suffix        # ".txt"
p.exists()      # 是否存在
p.read_text(encoding="utf-8")
p.write_text("内容", encoding="utf-8")

# 遍历目录
for file in Path("./").glob("*.py"):
    print(file)
```
