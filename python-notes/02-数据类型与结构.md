# 02-数据类型与结构

## 1. 基本数据类型

```python
# 数字
integer = 10          # 整数
floating = 3.14       # 浮点数
complex_num = 3 + 4j  # 复数

# 字符串
string = "Hello, Python!"
multiline = """多行
字符串"""

# 布尔值
flag = True  # 或 False

# 空值
nothing = None

# 查看类型
type(10)        # <class 'int'>
type("hello")   # <class 'str'>
```

## 2. 字符串操作

```python
text = "  Hello Python  "

# 常用方法
text.strip()       # 去除首尾空格 → "Hello Python"
text.lower()       # 转小写
text.upper()       # 转大写
text.replace("Python", "World")  # 替换
text.split(" ")    # 分割成列表

# 索引和切片
s = "Python"
s[0]     # 'P'
s[-1]    # 'n'
s[0:4]   # 'Pyth'（左闭右开）
s[::2]   # 'Pto'（步长为2）

# 字符串不可变！
# s[0] = 'p'  # ❌ 报错
```

## 3. 列表（List）

有序、可变、可重复。

```python
fruits = ["apple", "banana", "cherry"]

# 增删改查
fruits.append("orange")      # 末尾添加
fruits.insert(1, "mango")    # 指定位置插入
fruits.remove("banana")      # 删除指定值
fruits.pop()                 # 删除并返回最后一个
fruits[0] = "grape"          # 修改

# 切片
fruits[1:3]   # 第2到第3个元素

# 列表推导式（重点！）
squares = [x**2 for x in range(5)]  # [0, 1, 4, 9, 16]
evens = [x for x in range(10) if x % 2 == 0]
```

## 4. 元组（Tuple）

有序、**不可变**、可重复。

```python
coordinates = (10, 20)
# coordinates[0] = 5  # ❌ 报错，不可修改

# 解包
x, y = coordinates
```

## 5. 字典（Dict）

键值对存储，键唯一。

```python
person = {
    "name": "Alice",
    "age": 25,
    "city": "Beijing"
}

# 访问
person["name"]        # "Alice"
person.get("gender", "unknown")  # 安全获取，默认"unknown"

# 增删改
person["age"] = 26
person["gender"] = "female"
del person["city"]

# 遍历
for key, value in person.items():
    print(f"{key}: {value}")

# 字典推导式
squares = {x: x**2 for x in range(5)}
```

## 6. 集合（Set）

无序、不重复。

```python
nums = {1, 2, 3, 3, 3}  # 实际为 {1, 2, 3}
nums.add(4)
nums.remove(2)

# 集合运算
a = {1, 2, 3}
b = {2, 3, 4}
a & b  # 交集 {2, 3}
a | b  # 并集 {1, 2, 3, 4}
a - b  # 差集 {1}
```

## 7. 类型转换

```python
int("10")      # 10
str(100)       # "100"
list("abc")    # ['a', 'b', 'c']
tuple([1,2])   # (1, 2)
set([1,1,2])   # {1, 2}
dict([("a",1)])  # {'a': 1}
```
