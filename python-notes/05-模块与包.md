# 05-模块与包

## 1. 导入模块

```python
# 导入整个模块
import math
print(math.sqrt(16))

# 导入指定函数/变量
from math import sqrt, pi
print(sqrt(16), pi)

# 起别名
import numpy as np
from datetime import datetime as dt

# 导入所有（不推荐，易冲突）
from math import *
```

## 2. 自定义模块

文件结构：
```
my_project/
├── main.py
└── utils.py
```

`utils.py`：
```python
def helper():
    return "我是工具函数"

PI = 3.14159
```

`main.py`：
```python
from utils import helper, PI

print(helper())
print(PI)
```

## 3. 包（Package）

含有 `__init__.py` 的文件夹就是包：

```
my_package/
├── __init__.py
├── module_a.py
└── module_b.py
```

`__init__.py` 可以为空，也可以控制对外暴露的内容：
```python
# __init__.py
from .module_a import func_a
from .module_b import func_b

__all__ = ["func_a", "func_b"]  # from my_package import * 时导入的列表
```

## 4. `if __name__ == "__main__"`

```python
# 一个模块既可以直接运行，也可以被导入

def main():
    print("程序入口")

if __name__ == "__main__":
    main()  # 直接运行此文件时执行
```

## 5. 常用内置模块速查

```python
import os
import sys
import random
import datetime
import json
import re

# os: 操作系统接口
os.getcwd()       # 当前工作目录
os.listdir('.')   # 列出目录
os.path.exists('file.txt')

# sys: 系统相关
sys.argv          # 命令行参数
sys.path          # 模块搜索路径

# random: 随机数
random.randint(1, 100)
random.choice(["A", "B", "C"])

# datetime: 日期时间
from datetime import datetime
now = datetime.now()
print(now.strftime("%Y-%m-%d %H:%M:%S"))
```
